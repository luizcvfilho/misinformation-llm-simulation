# Documentation

This directory uses a purpose-based language policy.

## Language Policy

- Software and repository documentation must be written in English.
- TCC research, writing, and presentation materials must be written in Portuguese.
- The canonical institutional template must be preserved in its original language.
- Code, identifiers, and code comments must remain in English.

## TCC Documents

- `base_bibliografica_tcc.md`: annotated and verified literature base.
- `plano_escrita_tcc.md`: research question, methodological history, evidence map, writing plan, and current exploratory results.
- `template_tcc_ic_ufrj.md`: IC/UFRJ formatting rules, canonical template structure, and Overleaf synchronization requirements.
- `apresentacao_tcc_defesa_preparacao.md`: active checklist for preparing the final defense presentation.

The canonical LaTeX template is stored under `../templates/modelo-tcc-ic-ufrj-2025/`.
