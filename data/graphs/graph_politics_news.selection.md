# Political news for personality-chain experiments

`graph_politics_news.csv` contains 100 political news records selected from `data/raw/politics_news.csv`, plus one `__query_metadata__` record. All 21 original columns and every selected news-field value are preserved exactly. The original source and `graph_news.csv` were not edited.

## Selection

The selection is a qualitative hypothesis about material that may produce different rewrites under the six personality prompts in `src/misinformation_simulation/enums/personalities.py`. It was made without using simulation outcomes. It does not demonstrate greater chain separation or explain the similar averages in previous experiments.

The source has 5,519 news records. Screening required English, a politics category, a description of 150–3,000 characters and at least 25 whitespace-separated words, and a source duplicate flag other than true. This left 2,178 eligible distinct titles. Topic-keyword searches provided candidates; selected titles and complete available descriptions were reviewed before editorial selection. Keywords were not a final relevance classifier.

The choices emphasize explicit disagreements, policy trade-offs, evidence and attribution, human stakes, and opportunities for conciliation. The sample includes critical, supportive, cooperative, opinion, and analysis frames. It is purposive rather than random or representative. Unique IDs and normalized titles were required; repeated coverage of an event was limited during review. Two reports about the March No Kings protests intentionally retain contrasting source frames and share an event-group label. Broader thematic dependencies remain.

## Text and measurement limits

Every `content` value in the source is `ONLY AVAILABLE IN PAID PLANS`, and every selected `full_description` is empty. The supplied descriptions are the usable text, ranging from 158 to 2914 characters. Original HTML, boilerplate, punctuation, incomplete excerpts, and source wording were preserved.

The graph runner defaults to `description` as the body and also supplies the original `title` as context at every rewrite step. Title-only cues and incomplete excerpts can therefore influence rewrites. No external factual verification was performed: inclusion does not endorse a claim, label an article true or false, or establish source credibility. Attribution, denials, speculation, and opinion need to remain distinct when evaluating rewrites. Informational drift and internal contradiction are different from factual veracity, belief, exposure, and sharing behavior.

## Embedded metadata and reproducibility

The first data record uses the repository's `__query_metadata__` convention. Its `description` contains JSON with the entire original collection metadata under `source_metadata`, the other original metadata-row fields under `source_metadata_row_fields`, source and personality-file SHA-256 hashes, counts, screening rules, ordering, limitations, and a justification for each article under `selected_articles`. Persona contrasts in that array are hypotheses, not validated labels. The original request-history indexes describe the full source dataset; selection entries provide separate source and output indexes. CSV record numbers refer to parsed records, not physical lines, because quoted fields can span multiple lines.

Reproduce the selected news rows by reading `selected_articles` in array order, matching each `article_id` to the source CSV, and copying the original columns. Check the source hash before reproducing. Preserve the derived metadata row separately. With Python's standard `csv` module, call `csv.field_size_limit(10_000_000)` first: the combined metadata exceeds the default field-size limit. Pandas reads this file and the existing graph loader removes the metadata row before simulation.

## Use

Run the same dataset across the existing chains using distinct output prefixes and the same model and evaluation settings. No simulations were run while creating this dataset.

```powershell
uv run python scripts/run_interaction_graph.py --input data/graphs/graph_politics_news.csv --graph-config data/graphs/interaction_chains/05_ccpp.json --text-column description --news-id-column article_id --output-prefix politics_ccpp
```
