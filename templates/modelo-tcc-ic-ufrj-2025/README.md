## Preservation Rule

Do not edit `archive/` or `source/`. To start an Overleaf project or create a local working version of the thesis, make a complete copy of `source/` and work on that copy.

The entry point for the current version is `source/main.tex`. The `source/Old/` directory is retained only to preserve the received material exactly; it is not part of the current implementation and must not be used to create the thesis.

The template contains sample text, names, images, and references. They are not thesis content and must be replaced in the working copy.
## Overleaf Synchronization Reporting

Work performed from this template is not synchronized with Overleaf automatically. After every writing, review, or formatting task, the result must include an Overleaf synchronization checklist that:

- lists every file that was changed or must be changed, including `main.tex`;
- gives the exact path of each file in the Overleaf project;
- states the concrete action required, such as add, replace, remove, or upload;
- provides copy-ready content or precisely identifies the affected section;
- explicitly states when no file other than `main.tex` requires changes.

Bibliography changes must always identify this mapping:

```text
Repository: references.bib
Overleaf:   elementos-postextuais/referencias.bib
```
